# Conformance vectors

Every Pawnshake implementation must reproduce these exactly.

| File | Covers | Generated by |
|---|---|---|
| `movecode.json` | move codes: for each position (FEN), `legal[i]` is the move with code `i` | `go test ./movecode -update` in `go/` |
| `core.json` | varints, certificate, profile, genesis (hash, colors, keys), records (body, header, id, signature, wire, head), receipt, canonical order | `go test . -update` in `go/` |
| `zip215.json` | the 196 ZIP-215 Ed25519 edge cases (all must verify) | copied from `github.com/hdevalence/ed25519consensus` (BSD-3-Clause) |

Keys in `core.json` come from fixed seeds, so signatures are reproducible.
